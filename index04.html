物理與量測解析：
目前處於正常並聯狀態。發電機電力輸入 PDC 後分流為兩路：一路為大電瓶充電，另一路經由閉合的 PCR 繼電器對輔助小電瓶充電。
PDC Power Distribution Center
配電中心（引擎室保險絲盒總成）
位於引擎室左側。內含多層 PCB 控制電路板以及側邊的 Z-Case 大容量保險絲陣列（N1~N7）。所有發電機電力與大電瓶電力皆由此做全車分配。
PCR Power Control Relay
電源控制繼電器（實體大繼電器）
藏在右前內輪拱遮板下方、輔助小電瓶後方。常態下接點閉合（大小電瓶並聯充電）；Auto-Start 啟動瞬間通電斷開，切斷大小電瓶連繫，防止啟動壓降拉跨車內影音螢幕。診斷電腦將此繼電器稱為「啟動繼電器 3」。
PCR Control Relay PCR Pilot Relay
PCR 控制繼電器（先導微型繼電器）
焊接或插置在 PDC 內部的 PCB 電路板上。受 PCM 電腦控制，專門負責送出 12V 電源去驅動輪拱內那顆真正的實體 PCR 大繼電器。
PCM Powertrain Control Module
動力系統控制模組（引擎大腦電腦）
監控車輛運行條件、啟停條件以及 N2 與 N3 兩點之間的電壓差。當偵測到 N2 與 N3 壓差超過 2V 時，判定繼電器控制迴路異常，儲存故障碼 `P2AF5`。
IBS Intelligent Battery Sensor
智慧型電池感測器
直接整合在大電瓶負極樁頭上。內置分流電阻與微處理器，走 LIN-Bus 通訊線 即時回傳電瓶的電壓、充放電電流、溫度與 SOC（電池電量健康狀態）。充電時負極夾若直接夾在樁頭上會繞過 IBS，使庫倫計算失準。
BCM / CBC Body Control Module
車身控制模組 / 中央車身控制器
負責控制全車儀表、防盜、車門鎖、燈光及中控娛樂螢幕。由輔助小電瓶專責穩壓供電；當小電瓶耗盡斷電時，BCM 進入休眠，導致全車儀表黑屏、無法辨識啟動按鈕。
Fuse N3 (150A) Z-Case Fuse Array
PDC 側邊 150A 專用保險絲
位於 PDC 側邊保險絲陣列第 3 個位置。專門負責保護從小電瓶通往 PCR 及發電機的充電迴路。本故障案例中，因大電瓶正極未鎖緊，突波電流衝破 150A 上限導致其熔斷。
